# Adaptive Modulation Simulation

This project implements and evaluates adaptive modulation (BPSK, QPSK, 16-QAM) over an AWGN channel.

## How to run

1. Open MATLAB
2. Set the current folder to this project folder
3. Run scripts in order:
   - `adaptive_modulation_partA.m`   → BER vs SNR curves
   - `adaptive_modulation_partB.m`   → Adaptive modulation controller
   - `PartC_Performance_Evaluation.m`→ BER vs time, throughput, summary table

## Files included

- MATLAB scripts (.m)
- PNG plots
- summary_table.csv
- report.pdf
